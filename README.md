" 날씨와 일상을 연결하는 북고풍감성 프로젝트[weather]"

기획 의도
- Targer: 매일 반복되는날씨 확인이 지루하고 독특하고 재미있는 UIUX를 선호하는 젊은세대  
- concept : 레트로 감성
- core Value
  └─ 편린함 : 위치 기반으로 실시간 데이터로 필요한 정보를 제공
  └─ 즐거움 : 앱 접속 시 '장독대 닫기' 미니게임을 통해 소소한 재미를 제공
  └─ 독특함 : 할머니의 따듯한 말투로전해 듣는 '오늘의 운세'로 하루의 시작을 기분 좋게 제안

  사용한 툴 & 핵심 기술
  state
  └─ 스택 : Redux Toolkit
  └─ 구현 내용 : 날씨 정보, 게임 점수, 운세 데이터를 증간에서 관리하여 컴포넌트 간 데이터 동기화를 최적화      
  Logic
  └─ 스택 : React Hook
  └─ 구현 내용 : useEffect와 useState를 활용해 API 통신 및 실시간 상태 업데이트 로직을 분리
  Visual
  └─ 스택 : CSS Grid & Flex
  └─ 구현 내용 : 레트로 스타일의 레이아웃을 반응형으로 구현하여 다양한 기기에서 최적화된 뷰를 제공
  Date
  └─ 스택 : OpenWeatherMap
  └─ 구현 내용 : 위도/경도 기반의 정밀한 기상 데이터를 수집 및 가공


주요 기능
[실시간] 사용자를 위한 맞춤 날씨 가이드
- 단순히 온도만 보여주는 것이 아니라 데이터를 분석해 산책하기 좋은 정도를 시각적으로 제안하고 편리한 UI를 통해 한눈에 파악이 가능
