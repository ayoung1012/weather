<h3>기획 의도</h3>
단순한 정보 전달을 넘어 사용자에게 정서적인 유대감과 시각적 즐거움을 주는 것을 목표로 했습니다.

- Target: 매일 반복되는날씨 확인이 지루하고 독특하고 재미있는 UIUX를 선호하는 젊은세대
- 컨셉: 픽셀 아트 기반의 레트로 감성
- core Value
  - 편리함 : 위치 기반으로 실시간 데이터로 필요한 정보를 제공합니다.
  - 즐거움 : 앱 접속 시 '장독대 닫기' 미니게임을 통해 소소한 재미로 채웠습니다.
  - 독특함 : 할머니의 따듯한 말투로 전해 듣는 '오늘의 운세'로 기분 좋은 하루의 시작을 제안합니다.

  <h3>사용한 툴 & 핵심 기술</h3>
  state (Redux Toolkit)
  Logic (React Hook)
  Visual (CSS Grid & Flex)
  API (OpenWeatherMap)


  - state (Redux Toolkit)

주요 기능
[실시간] 사용자를 위한 맞춤 날씨 가이드
- 단순히 온도만 보여주는 것이 아니라 데이터를 분석해 산책하기 좋은 정도를 시각적으로 제안하고 한눈에 들어오는 UI로 편리함을 극대화했습니다.

[재미] 10초의 승부 '장독대 닫기' 게임
- 앱을 사용하는 짧은 순간에도 즐거움을 느낄 수 있도록 설계했고 React의 상태 변화를 이용한 미니게임을 통해 사용자의 몰입감을 높였습니다. 

[독특함] 할머니가 들려주는 오늘의 운세
- 픽셀 아트로 구현된 '할머니' 캐릭터가 따뜻한 스토리텔링이 가미된 운세를 들려주며 친근한 말투를 통해 사용자에게 친근한 이미지를 각인시켜줍니다.      
  
프로젝트의 차별점
1. 실시간 API 연동으로 앱의 본질인 '정보 전달'에 충실했습니다.
2. 게임 요소를 결합해 재방문율을 높였습니다.
3. 레트로 감성의 픽셀 아트와 할머니 페르소나를 통해 친근한 이미지를 형성했습니다.
